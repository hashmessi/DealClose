# Phase 2: AI Structuring + Document Generation - Plan

## Objectives
- Integrate OpenAI GPT-4o to transform raw SerpApi market data into a structured deal object with per-field confidence scores.
- Flag uncertain fields (<85% confidence) for human review routing.
- Integrate Nutrient DWS / PDF generation to create a Purchase Offer PDF with contingency branching and calculated closing costs.
- Store document metadata in Xano and render the PDF inline in the browser.

<task>
  <read_first>
    - src/app/api/deal/route.ts
  </read_first>
  <action>
    Create `src/app/api/ai/extract/route.ts` API endpoint.
    - Accepts POST request with `{ rawSerpData, address }`.
    - Uses OpenAI `gpt-4o` (or structured fallback parser if API key is unconfigured) to extract:
      - `offer_price` (number)
      - `earnest_money` (number)
      - `closing_date` (string)
      - `contingency_financing` (boolean)
      - `contingency_inspection` (boolean)
      - `seller_concessions` (number)
      - `closing_costs_buyer` (number - calculated as 2% of offer_price)
      - `closing_costs_seller` (number - calculated as 1.5% of offer_price)
      - `confidence_scores`: object mapping field names to confidence percentages (0-100)
      - `flagged_fields`: array of field keys where confidence < 85.
    - Return JSON response `{ success: true, dealTerms, flaggedFields }`.
  </action>
  <acceptance_criteria>
    - `src/app/api/ai/extract/route.ts` exists.
    - The route calculates confidence scores and tags fields below 85%.
  </acceptance_criteria>
</task>

<task>

  </read_first>

    Create `src/app/api/doc/generate/route.ts` API endpoint for PDF document creation.

      - Header: "REAL ESTATE PURCHASE & SALE AGREEMENT"
