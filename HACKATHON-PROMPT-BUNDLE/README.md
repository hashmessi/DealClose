## HOW TO USE

### Step 1: Fill `00-MASTER-SYSTEM-PROMPT.md`
Paste this as the system prompt in your AI agent (Gemini, Claude, GPT-4) before starting any prompt in this bundle.

### Step 2: Work through prompts in sequence
Open each prompt file, fill the `[CONTEXT]` section at the top (takes 2 min), then run it.

### Step 3: Carry outputs forward
Each prompt produces outputs that feed into the next. The `[PASTE from Prompt XX]` markers tell you exactly what to carry forward.

### Step 4: Use `07-DEBUG-RECOVERY.md` on demand
When you hit an error, switch to the debug prompt. Don't lose time brute-forcing.

## TIME DISCIPLINE RULES

**The most dangerous hackathon mistake is over-building early features.**

- If a phase takes longer than budget → cut scope, move forward
- P0 features only until 3:00
- No new features after 3:30
- Deployment must start by 4:15 — no exceptions
- Demo prep is mandatory — a working product with no pitch loses to a weaker product with a great pitch
